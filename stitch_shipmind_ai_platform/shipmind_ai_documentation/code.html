Getting Started with ShipMind AI

ShipMind AI is a predictive logistics platform that leverages deep neural networks to optimize global supply chains. Integrate our SDK into your stack in minutes and start predicting transit delays before they happen.

Installation

Install the ShipMind SDK using your preferred package manager. We recommend using @shipmind/core for modern TypeScript environments.

Terminal
npm install @shipmind/core
# or
yarn add @shipmind/core

Initialization

Initialize the client using your API key found in the ShipMind Console.

TypeScript Python content_copy Copy 
import { ShipMind } from '@shipmind/core';

// Initialize the client
const client = new ShipMind({
  apiKey: 'SM_LIVE_928374',
  region: 'us-east-1'
});

// Optimize a route
const results = await client.optimize({
  origin: 'SFO',
  destination: 'LHR'
});
